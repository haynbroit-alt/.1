# Cycle C-0002 (24/11/2026) : la boucle de vérification obligatoire

**Demande du propriétaire.** Chaque module suit le cycle action → preuve → vérification indépendante → détection
des erreurs → correction → nouveau test. Aucun agent ne valide seul son propre travail.

**Résultat.** La règle est inscrite dans le code : un contrôle dont le contrôleur est le producteur est refusé.
Chaque étape de la chaîne n'est PROUVÉE que par un contrôleur indépendant. Les vérifications indépendantes ont
trouvé 50 erreurs que l'auteur n'avait pas vues :
- 46 dans le code, en cinq revues : 19, puis 10, puis 7, puis 4 brèches, puis 6 chemins de validation par la
  mère elle-même ;
- 2 dans le portefeuille ;
- 1 dans le pipeline ;
- 1 dans les sorties : une empreinte que la garde a prise pour un SIREN.

Toutes sont corrigées, chacune avec un test qui échoue sur le code d'avant correction. Seul reste ouvert ce qui
relève d'un autre dépôt (VELYX) ou du propriétaire.
